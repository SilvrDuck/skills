# Don't write README TLDRs for the user

When time to update the readme, ask the user for the skill tldr and copy verbatim.

# Audit the description for bleed before pushing

At the end of building or editing a skill, before pushing, re-read the `description` and audit for bleed — body content (workflow steps, behavioral stances, rules) that leaked into the description. The description is what + when + triggers only; cut anything that belongs in the body.
